# BoreasOS
Batizado em homenagem a Bóreas, o deus grego do vento norte, o BoreasOS é uma distribuição Linux baseada em Arch Linux. A proposta é unir a base atualizada e flexível do Arch com um desktop simples, leve e pronto para usar logo no primeiro boot.
Destaques
Base Arch Linux, com pacotes sempre atualizados
Desktop XFCE, rápido e leve, com painel e menu iniciar
Firefox, terminal, gerenciador de arquivos, bloco de notas, calculadora, visualizador de imagens e reprodutor de vídeo
Português do Brasil, teclado ABNT2 e horário de São Paulo por padrão
Tema escuro, ícones Papirus e identidade visual própria
Modo live: dá para testar o sistema direto do pendrive, sem instalar
Status: em desenvolvimento. Por enquanto a ISO roda em modo live, e o instalador gráfico ainda está nos planos.
